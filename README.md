# VRC Advanced World Tools

Tools for developing large VRChat worlds as a team, published as VPM packages.

| Package | What it does |
|---|---|
| [VPM Package Sync](Packages/com.livedimensions.vpmpackagesync/README.md) | Keeps every machine's packages the same as the project's, and adds missing VPM listings to VCC/ALCOM. |
| [UdonSharp Fast Build](Packages/com.livedimensions.udonsharpfastbuild/README.md) | Makes UdonSharp's scene build step linear instead of O(n²) for worlds with many cross-referenced UdonSharpBehaviours. |

## Installing

Add this listing to VCC/ALCOM, then add the packages to your project from there:

```
https://livedimensions.github.io/VRC-Advanced-World-Tools/index.json
```
